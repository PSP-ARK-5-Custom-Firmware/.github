## 📥 Installation Guide

### Official Firmware Installation

1. Confirm that the PSP is running a supported system software version.
2. Obtain the appropriate FasterARK package from the official project repository.
3. Extract the package to the PSP storage device.
4. Run FasterARK from the PSP interface.
5. Follow the installer instructions for the selected installation method.

### Existing Custom Firmware

1. Identify the currently installed custom firmware.
2. Select the corresponding FasterARK upgrade procedure.
3. Follow the documented installation sequence.
4. Complete the installation using the project-provided tools.

### Permanent Installation

ARK-5 provides a Custom IPL installation path through its associated installer components. The available method depends on the PSP model and installation configuration.

Use the model-specific instructions provided by the project before changing IPL or flash components.
